## Install

`.npmrc`:

```ini
@andysu:registry=https://dixonsolutions.github.io/AndySU/npm/
```

```sh
npm install @andysu/capacitor && npx cap sync android
```

The Android side needs the [Maven repository](/android/gradle-plugin#repositories) in the app's Gradle
settings. Package the finished APK with `andysu split --transparent`. In transparent mode web assets
are content like any other: a release applies on restart or on the next start, depending on
`live_fallback`. Hot updates (`andysu pack --hot`) need stub mode, where a `Payload` reloads the
content. See [Ship an existing APK](/tutorials/existing-apk#when-does-an-update-apply).

## Use it

```ts
import { AndySU } from '@andysu/capacitor';

await AndySU.checkNow();
await AndySU.setApplyPolicy({ policy: 'restart' });   // 'live' | 'restart' | 'next_start' | null
await AndySU.setUpdateMode({ mode: 'download_only' });   // 'auto' | 'download_only' | 'check_only' | 'off' | null
const handle = await AndySU.addListener('status', s => console.log(s.state, s.release));
```

| Method | Returns |
|---|---|
| `info()` | `{present, apiLevel?, version?, isFactory?, slotDir?}` |
| `status()` | `{state, release?, ...}` |
| `checkNow()`, `applyNow()`, `restartNow()`, `markHealthy()` | `Promise<void>` |
| `setApplyPolicy({ policy })`, `applyPolicy()` | override; read `{policy}` |
| `setUpdateMode({ mode })`, `updateMode()` | `'auto'`, `'download_only'`, `'check_only'`, `'off'` or null for the configured mode; read `{mode}` (null on a host older than API level 3, where the setter does nothing) |
| `addListener('status', cb)` | listener handle |

On platforms without AndySU (web, iOS) every call resolves with neutral values.
